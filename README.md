# SkinDraw 电子皮肤热力图

当前 main 版：连接硬件 → 各块自动标定（每个有效点位约3秒、270个有效样本）→ 实时显示按压响应。

本项目现在有独立的 Git 仓库。`main` 默认校准后显示 ΔADC；`test` 默认跳过校准、显示原始 ADC。关闭程序后，在本目录执行 `git switch main` 或 `git switch test`，再重启软件即可切换。已有未提交修改应先保存后再切换分支。

支持明文和v0.5二进制数据、自动排列、单块拖动、旋转镜像、接收帧率和运行日志。

不规则皮肤可在左侧选中 BLOCK 后点击 **编辑有效点位**：点击格子隐藏没有传感器的位置，保存后自动记住，重启恢复。隐藏位置透明显示，不参与统计及自动色阶；原始矩阵保留。连接中修改点位，仅该块重新自动标定。旋转、镜像时点位同步变化。

在左侧“皮肤块布局”点击 **恢复人体预设（14块）**，按预设部位摆放：正面为肩、上臂、下臂、胸腹与手（BLOCK 1～8、11～12）以及大腿（13/14），右侧背面区为9背部和10腰部。未连接的位置仅显示占位框。拖动后可再次一键恢复，保留旋转、镜像和基线；点击“恢复自动排列”返回紧凑网格。保存采集布局后，重启恢复保存时的人体预设或自动排列；未保存时默认自动排列。

人体预设按当前显示尺寸紧凑摆放，手掌位于大腿两侧，肩臂贴近胸腹，背面紧邻正面。旋转后自动调整间距；如已手动拖动，点击“恢复人体预设（14块）”重新应用紧凑布局。

在 `collection` 分支，调整好各块摆放位置、方向和有效点位后，点击 **保存并固定采集布局**。完整预设保存在本地 `configs/collection_layouts/`，下次启动自动调用，连接硬件后沿用保存的位置和方向。也可随时点击 **调用本地采集布局** 重新恢复；需要修改方向或点位时点击 **调整采集布局**，再次保存生成新版本。拖动位置后会提示“位置待保存”，可以直接保存。支持逐步补齐 1～14 号皮肤。旧版布局继续可读，但未记录的手动位置需要调整并重新保存一次。动作录制使用界面框上部的采集栏，原始 ADC 按 CSV 方案写入 `dataset/`。

## 启动

双击 **start.pyw**，或在项目目录执行：

```powershell
./.venv/Scripts/python.exe -m skin_draw
```

首次安装或换电脑时，安装Python 3.11或更高版本后运行：

```powershell
powershell -ExecutionPolicy Bypass -File ./install.ps1
```

## 使用

1. 接通硬件，选择COM端口及与硬件一致的波特率：115200（1倍）、230400（2倍）、460800（4倍）、921600（8倍）、1843200（16倍），默认115200。数据格式为8N1，协议和发送方式默认自动识别。
2. 松开传感器，点击“连接并校准”，等待各块完成自动标定（每个有效点位约3秒、270个有效样本）。
3. 按压观察颜色；默认受压 ADC 变小，显示值为基线与当前值之差。
4. M3 滤波默认关闭，直接使用当前 ADC 计算响应；需要时点击“M3 滤波：关闭 · 点击开启”，再次点击即可关闭。开启后可抑制短暂低值，但真实变化可能延迟约30帧跟随；切换后请松开传感器，等待重新标定。归一化独立控制，CSV 原始 ADC 不受影响。
5. 可拖动单块、旋转镜像；“适应窗口”查看全部，“断开硬件”结束接收。

“导出PNG”是热力图截图。`collection` 分支已集成训练数据录制，每条动作保存 `raw.csv`、`baseline.json` 和 `meta.json`，有效点位使用全局版本化配置。点击开始后保持约1秒无接触，基线检查通过并提示后再执行动作。采集时可查看实时滚动波形；停止后后台完成写盘，再查看完整波形、人工确认接触起止。标注保存成功后清空显示，不另存波形图片。详见[逐条无接触基线采集](docs/逐条无接触基线采集.md)和[采集波形与接触起止标注](docs/采集波形与接触起止标注.md)。

# SkinDraw 电子皮肤热力图

当前 main 版：连接硬件 → 各块各行独立采集约1秒、至少30个有效样本 → 实时显示按压响应。

本项目现在有独立的 Git 仓库。`main` 默认校准后显示 ΔADC；`test` 默认跳过校准、显示原始 ADC。关闭程序后，在本目录执行 `git switch main` 或 `git switch test`，再重启软件即可切换。已有未提交修改应先保存后再切换分支。

支持明文和v0.5二进制数据、自动排列、单块拖动、旋转镜像、接收帧率和运行日志。

不规则皮肤可在左侧选中 BLOCK 后点击 **编辑有效点位**：点击格子隐藏没有传感器的位置，保存后自动记住，重启恢复。隐藏位置透明显示，不参与统计及自动色阶；原始矩阵保留。连接中修改点位，仅该块重新采集稳定基线。旋转、镜像时点位同步变化。

在左侧“皮肤块布局”点击 **恢复人体预设（14块）**，按示意图①～⑭对应BLOCK 1～14摆放：正面为肩、上臂、下臂、手、胸腹与大腿，右侧背面区为13背部和14腰部。未连接的位置仅显示占位框。拖动后可再次一键恢复，保留旋转、镜像和基线；点击“恢复自动排列”返回紧凑网格。预设模式在本次运行中保留，重启后默认自动排列。

人体预设按当前显示尺寸紧凑摆放，手掌位于大腿两侧，肩臂贴近胸腹，背面紧邻正面。旋转后自动调整间距；如已手动拖动，点击“恢复人体预设（14块）”重新应用紧凑布局。

## 启动

双击 **start.pyw**，或在项目目录执行：

```powershell
./.venv/Scripts/python.exe -m skin_draw
```

首次安装或换电脑时，安装Python 3.11或更高版本后运行：

```powershell
powershell -ExecutionPolicy Bypass -File ./install.ps1
```

## 使用

1. 接通硬件，选择COM端口及与硬件一致的波特率：115200（1倍）、230400（2倍）、460800（4倍）、921600（8倍）、1843200（16倍），默认115200。数据格式为8N1，协议和发送方式默认自动识别。
2. 松开传感器，点击“连接并校准”，等待各块完成稳定基线校准（各行约1秒且至少30个有效样本）。
3. 按压观察颜色；默认受压 ADC 变小，显示值为基线与当前值之差。
4. 任一有效点相对上一有效值突变超过800时，本次该行的有效点保持上一有效值；隐藏空位不触发过滤。
5. 可拖动单块、旋转镜像；“适应窗口”查看全部，“断开硬件”结束接收。

“导出PNG”是截图。**训练数据录制仍处于设计阶段，尚未集成到主程序。** H5样例是独立生成的模拟数据。

| `start.pyw` | 双击启动 |

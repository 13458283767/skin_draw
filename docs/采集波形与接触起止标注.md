# 采集波形与接触起止标注

更新日期：2026-11-02。适用于 collection 分支。

## 操作流程

1. 连接硬件、固定采集布局，选择参与者、场次和动作。
2. 点击开始采集，先保持约1秒无接触，等待“可以开始动作”的提示。热力图下方自动显示已配置各块的滚动波形，显示最近约10秒；橙色区为基线段。详见[逐条无接触基线采集](逐条无接触基线采集.md)。
3. 点击停止采集。程序立即关闭本条接收边界，在后台完成 raw.csv、meta.json 和索引的写入，热力图继续更新。
4. 文件关闭后，后台从 raw.csv 读取本条完整波形。此时原始数据已经保存，不需要等待人工确认才落盘。
5. 程序已按接触检测自动标出响应区间，两条竖线预填在首末个超阈值帧上。可直接确认，也可拖动竖线或输入秒数微调。
6. 点击“确认起止并保存”。meta.json 成功更新后清空本条图表数据，绘图控件继续复用，可开始下一条。

两个时间相对于本条录制开始，与 raw.csv 的 time_s 一致。起点必须早于终点，且两端均在录制时长内；有合格逐条基线时，接触开始不得早于“可以开始动作”的提示。

自动标注的规则与边界：

| 情况 | 写入结果 |
|---|---|
| 连续多帧超过起止阈值 `edge_counts` | `status=auto`，起止取首末个超阈值帧 |
| 只超阈值一帧 | 不写区间，保持 `unlabeled`，避免把单帧毛刺当动作 |
| 录制结束时仍有块高于 `edge_counts` | 仍写 `auto`，但 `auto.open_at_end=true`，界面提示终点不可信 |
| 没有连接基线、检测不可用 | 保持 `unlabeled` |

自动区间是**可测响应区间**，不是皮肤真实接触区间：短促动作的松开拖尾会被计入终点。因此 `status` 记为 `auto` 而不是 `confirmed`；人工确认后覆盖为 `confirmed`，原自动值进入 `annotation_history`。

三个阈值分工：

| 阈值 | 默认 | 作用 | 依据 |
|---|---:|---|---|
| `threshold_counts` | 100 ADC | 判定哪些块被接触，供区域统计与语义检查 | 区域需要一个明确的“确实被按到”的门槛 |
| `onset_counts` | 20 ADC | 起点 | 只在被接触块上取，偏灵；能抓住握持、推压的缓爬坡起步 |
| `edge_counts` | 50 ADC | 终点，以及“是否仍在接触” | 接触块释放后的余振与漂移实测可达 29 ADC，再低会被当成长时间接触 |

参与起止判定的块必须先达到 `edge_counts`：未接触块即使有 20～49 ADC 的波动，也不会计入区间。`edge_pad_s` 可在两侧对称外扩，默认 0 表示不外扩，只能向空发，且起点不会早于动作提示时刻。

**不将开始/停止按钮时间当作接触起止**，也不把整段录制当作动作段。连续拍击若被定义为一次动作，自动区间就是整组接触的外边界，仍可人工调整。

“暂不标注”会保留自动检测结果与原始文件，清空显示后继续采集；没有自动结果的样本则保持未标注。关闭窗口也不会伪造标注。保存失败会保留图表和选点，显示错误并允许重试。

起止确认与已有的“标记有效 / 作废”是两个不同操作：保存标注不会自动将质量不合格的样本变成有效样本。

## 波形表示什么

- 每条曲线对应一个已配置皮肤块，块号来自固定布局，不写死为 8 块。图例使用现有人体预设中的部位名称，例如右肩、左肩、右上臂、胸部；左右指人体自身。当前 1 号对应右肩、2 号对应左肩，未配置名称的块显示“未分配部位（编号）”。原始数据仍使用 block_id，显示名称不改变数据映射。
- 当前纵轴是该块**有效点的平均原始 ADC**，使用与 CSV 一致的保存坐标和有效掩码。
- 原始 ADC 通常受压下降，因此曲线下降可能代表接触。这里不是归一化热力图强度，也不是已完成逐条静息校正的响应。
- 波形显示不改变热力图的校准、滤波或归一化设置。热力图在初始标定后使用固定连接基线；逐条采集另行计算前1秒原始基线，用于本条接触区域统计并保存供训练使用。
- 大量点只在显示时聚合为时间桶内首值、最小值、最大值和末值，保留短促峰谷。所有原始行仍完整写盘。
- 实时预览允许跳过显示数据；最终完整图由已关闭的 CSV 重建。
- 超过 0.05 秒的相邻接收间隔会在图中断线。这是显示规则，不是硬件丢包判定，也不改变已有质量检查阈值。长记录的概览桶内存在间断时会保守显示缺口，不连成假平台。
- 完整波形覆盖整条记录，但屏幕上是有界点数的概览，不承诺每一个原始点均单独显示。

块均值可能弱化单点局部接触，人工判断不清时应保留未标注状态，不能为了完成操作强行指定边界。

## 保存内容

raw.csv 的原始值、列结构及时间戳保持不变，包含前1秒基线段。新界面记录 meta 格式版本为1.4，保留已有字段，增加本条 baseline.json 的引用与检查状态。

确认后的 annotation 示例（时间只是示例）：

```json
{
  "scope": "trial",
  "action_start_s": 1.25,
  "action_end_s": 3.8,
  "status": "confirmed",
  "source": "manual",
  "updated_at": "2026-10-25T15:00:00+08:00"
}
```

自动检测写入的 annotation（尚未人工确认）：

```json
{
  "scope": "trial",
  "action_start_s": 2.286,
  "action_end_s": 3.345,
  "status": "auto",
  "source": "contact_activation_v1",
  "updated_at": "2026-11-02T15:28:23.501+08:00",
  "auto": {
    "threshold_counts": 100.0,
    "onset_counts": 20.0,
    "edge_counts": 50.0,
    "edge_pad_s": 0.0,
    "contact_frames": 58,
    "open_at_end": false
  }
}
```

两种都没有时，两端为 null，status 为 unlabeled，source 为 null。标注采用临时文件替换方式写入；若已有 auto 或 confirmed 标注，再次修改会将前一次标注保存到 annotation_history。

**不额外保存波形截图、波形 CSV、显示缓存或绘图对象。** 原始数据、布局和标注即可重建本版原始 ADC 波形。baseline.json 保存实际估计的本条基线及质量报告，不是波形显示缓存。

## 性能与线程边界

```text
原始接收 → 原有写盘队列 → 独立 CSV 写入线程
        → 原有显示处理 → 热力图
        → 非阻塞显示队列 → 预览摘要线程 → 低频波形刷新

点击停止 → 立即关闭接收边界
        → 后台等待 CSV 线程真正退出、完成元信息和索引
        → 后台读取完整 CSV → 显示完整概览

确认边界 → 后台写入 meta.json → 成功后清空显示
```

- 原始行先进入写盘队列，之后才尝试入显示队列；两者不是竞争消费同一个队列。
- 显示队列容量 2048 条，每块实时摘要缓存最多 4096 点，停止时可直接丢弃未绘制的预览。
- 实时图最多约每秒 10 次更新；单次更新较慢时自动降低刷新频率。有待提交热力图更新时优先让热力图处理。
- 不修改原有热力图 4 ms 最小提交间隔。
- 取消“显示实时波形”会停止新显示数据入队和重绘，CSV 与热力图继续工作；停止后仍可以查看完整图。
- 后台收尾期间禁止开始下一条、修改身份和回收该样本；写盘线程尚未结束不能提前宣告成功。
- 关闭程序时等待后台保存完成；不会通过丢弃写盘队列来加速退出。
- 完整图流式读取，按块保存固定数量的摘要桶，不把整条原始矩阵全部载入内存。

增加任何绘图都有一定 CPU 与 UI 开销，不能承诺绝对零延迟。本设计避免让绘图阻塞写盘、避免停止时同步等待磁盘，并提供关闭实时预览的选项。实际硬件、磁盘与可见窗口下的表现仍需试采验证。

## 验证方法

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/benchmark_collection_waveform.py
```

基准程序使用临时目录，不打开串口，不写入正式数据集。它模拟 8 块、206 个有效点、每块目标 100 Hz，按“关闭—开启—开启—关闭”的顺序比较热力图更新、接收回调、写盘队列和丢弃记录。结果保存到已忽略的 artifacts/collection-waveform-benchmark.json。

该基准为离屏模拟，记录的热力图指标是提交计算耗时与间隔，不等同于真实屏幕端到端延迟。实机验收应另外检查串口接收间断、实际热力图流畅度和写盘记录完整性。

2026-10-25 本机一次 A/B 运行结果如下。每轮 3 秒、预期 2400 行，全部原样保存，软件写盘丢弃为 0。这组数值用于记录验证事实，不作为硬件性能保证。

| 轮次 | 实时波形 | CSV 行数 | 写盘队列峰值 | 热力图提交耗时 P95 / ms | 热力图提交间隔 P95 / ms |
| --- | --- | --- | --- | --- | --- |
| 1 | 关 | 2400 | 16 | 2.015 | 12.163 |
| 2 | 开 | 2400 | 8 | 1.621 | 12.336 |
| 3 | 开 | 2400 | 8 | 1.743 | 13.051 |
| 4 | 关 | 2400 | 8 | 2.001 | 12.591 |

开启波形时，实时及完整图合计刷新 24—25 次；波形更新耗时 P95 为 2.628—3.146 ms。停止按钮回调为 0.600—2.076 ms，后台写盘与重建耗时不包含在按钮回调中。

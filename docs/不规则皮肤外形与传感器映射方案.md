# 不规则皮肤外形与传感器映射方案（待审阅）

依据：`E:/研究生资料/电子皮肤/尺寸.ppt`，共 9 页、14 块皮肤。此文件是设计方案，不修改当前采集或绘图程序。

## 1. 预期效果

串口继续发送完整矩阵，明文、二进制协议都保持现状。软件根据预先保存的皮肤外形与传感器位置，只在实际有传感器的位置画小正方形；每个小方块独立随按压改变颜色。皮肤底板绘制浅色轮廓，外部透明，空位没有传感器方块。

胸部发送 50 个矩阵槽位，但按照 PPT 只显示 40 个真实传感器。胸部外形由下方矩形与上方梯形组成：底宽 40 cm，顶宽 14 cm，下段和上段各高 9 cm。保留 PPT 中传感器的排列，不将 40 个值压缩成新的满矩形。

已存在的单块拖动、左右 90° 旋转、上下/左右镜像、缩放、固定色阶和导出功能继续可用。外轮廓、有效点位、编号和选中标记同步变换。

## 4. 核心设计：原始矩阵、有效点位和显示坐标分开

每个皮肤模板保存以下内容，放在独立 JSON 配置中，不散落在界面代码里：

- 模板名称、图纸编号，例如 chest / 胸部 / ⑦。
- 接收矩阵尺寸：以真实帧头为准。
- 实际传感器列表：图纸点号、原始矩阵 row/col、皮肤内部显示 x/y。
- 外轮廓顶点、尺寸单位、示意方块大小。
- 有效点位掩码：根据传感器列表在原始矩阵中生成的布尔表。
- 配置版本及映射是否已核对。

另外保存设备绑定表：BLOCK ID → 模板。每块的画布位置、旋转与镜像写入独立布局配置，避免修改显示方向时改变原始点号或采集索引。

两种视图共用一份数据：

1. **实际皮肤图**：按外形和真实点位显示，作为日常使用默认视图。
2. **原始矩阵**：保留完整接收行列，用于检查零值占位、接线顺序和异常数据；可同时显示图纸点号与原始行列。

同一尺寸可能对应不同部位，例如胸部、背部、腹部、腰部均为 50 槽位，因此不能只根据矩阵尺寸自动决定模板。完成一次绑定后，再按 BLOCK ID 自动应用。

## 5. 空位与数值 0 的处理

使用固定有效点位表判定传感器是否存在，不按每一帧的 `ADC != 0` 重建图形。

| 状态 | 显示和处理 |
|---|---|
| 模板中的空位，串口填0 | 不画方块、不选点、不参与校准、统计或突变判定 |
| 真实传感器响应 ΔADC=0 | 保留方块，用色阶最低色显示 |
| 真实传感器原始 ADC=0 | 保留物理位置，按现有突变规则处理，可标注异常，不能直接当空位 |
| 真实传感器尚未校准 | 在固定位置显示灰色方块 |
| 整块暂未收到数据 | 保留外形、位置和点位，沿用现有过期提示 |

前30帧数据可以辅助生成候选空位表，但只能用于核对；有效传感器也可能因故障持续为0，所以不允许仅凭零值自动确认永久空位。

## 6. 接入现有校准和过滤

建议数据顺序：串口解析 → 原始完整矩阵 → 查找模板和有效点位 → 异常过滤 → 30帧基线与响应 → 按物理坐标着色。

- 原始矩阵完整保留，方便诊断和记录；不会删除行、挤走空位或改变数组索引。
- 每块仍按前30帧有效原始样本校准，只有有效传感器参加求平均。校准期间空位不会阻碍进度。
- 保留现有“任一点突变超过1000，丢弃本次该行”的规则，但比较范围仅限该原始数据行内的有效传感器，替代计数也只计真实点位。
- 过滤中的“行”仍是串口原始矩阵行。旋转、镜像或物理重排之后，看起来的一条横排不一定对应一条数据行，不能改变过滤分组。
- 按现有规则，含异常有效行的矩阵不计入该块校准；其他块继续。固定空位的0不是异常点。
- 最小值、最大值、平均值、自动色阶和传感器总数只计算有效点位。标题可显示“胸部 · 40点 / 50槽位”。

## 7. 交互、自动布局与持久化

- 只展示已连接并收到有效数据的皮肤块；配置中存在但未连接的块不占画布。
- 根据外轮廓外接范围自动排列，按统一尺度缩放以保留各块尺寸关系，14块整体适应窗口；放大后查看点号。
- 保留每个传感器一个方块，统一响应色阶，不引入空间平滑或插值。
- 单块拖动移动外轮廓和全部传感器；旋转、镜像围绕该块局部坐标统一计算。
- 支持“适应窗口”“恢复自动排列”“显示外轮廓”“实际皮肤图 / 原始矩阵”切换。
- 保存模板绑定、已核对映射和手动布局，重启可恢复。基线按现有行为每次连接重新校准。
- 收到不认识的 ID 或尺寸不匹配时，暂以原始矩阵显示并提示未绑定/尺寸不匹配，不套用错误的人体部位。只影响该块。

## 8. 一次性点位核对

目前用户尚不确定①～⑭与 BLOCK ID 的关系，也未确认胸部帧头是10行5列还是5行10列，因此模板与原始通道不能直接写死。

建议提供一个简单的核对面板：选择收到的 BLOCK → 选择部位 → 并排显示原始矩阵和图纸点号 → 依次按压指定点 → 检查变化最大的原始通道 → 核对并保存。

先核对1号点和跨行的几个点，判断是否行列互换、上下颠倒、左右颠倒或蛇形扫描。若映射规则明确，可据此生成整块映射并抽查；若为任意接线，则逐点登记。左右对称部位分别核对，不假定它们的接线也互为镜像。

核对面板使用原始矩阵差值提示候选通道，并保留手动确认，避免异常跳点被误当成目标传感器。映射确认后，使用时不需要重复配置。

## 9. 实施顺序与验收

第一步：创建14块的外形、图纸点号及有效点位模板，使用模拟编号数据预览，先确认胸部40点的效果。此阶段接收通道映射标为未核对。

第二步：加入设备绑定和点位核对，验证一个胸部块与一个不规则下臂块，再推广到全部14块。接入现有明文/二进制解析、校准、过滤和统计。

第三步：完成拖动/旋转/镜像联动、配置保存与14块布局测试。

验收重点：

- 胸部和背部各显示40点，而非50个方块；所有图示模板合计438点。
- 按压图纸上的指定点时，对应小方块改变颜色，读数仍显示正确原始行列。
- 空位不会参与色阶、统计、校准或触发整行过滤。
- 真实传感器测到0或响应为0时，外形和点位数量保持稳定。
- 两种协议输入相同矩阵时，显示结果一致。
- 旋转和镜像后空位、编号和选点同步变换，原始行过滤仍正确。
- 实时刷新只更新有效点颜色，不反复创建轮廓或重新生成布局。
- 14块在最小窗口下可整体显示，尺寸不匹配、漏帧和重启恢复有明确行为。

## 10. 维护边界

建议新增 `skin_profile.py`（模板校验、有效掩码、坐标映射）、`profiles/`（14块配置）、`ui/skin_shape_item.py`（轮廓与传感器绘制）、`ui/mapping_panel.py`（一次性核对）。现有协议模块保持接口，过滤和基线模块增加有效点位参数。绘图按块缓存静态几何，避免每帧创建438个独立控件。
